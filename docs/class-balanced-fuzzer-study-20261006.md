# Prospective class-balanced contextual study, phase 02

This protocol declares a fresh bounded experiment before phase 02 training. The initial 54-attempt contextual study and its failed retention decision remain separate archived evidence. No initial candidate development or fixture errors are used to choose this grid. The development and validation partitions have been used in earlier exploratory studies; this experiment does not establish untouched generalization. The protected final partition remains uninspected and unscored.

The base is the exact live `privoke-balanced` artifact, version `v0.3.0+train.2`, file SHA-256 `87065d573970eec9b753102599789ebcb199b9b9d75e787b3b06e914137cdd92`. Every attempt independently starts from its weights. The grid is 24 attempts: heads or final encoder block plus heads; uniform control or `class_balanced_contextual_v1`; learning rate 0.003 or 0.01; seeds 42, 1337 or 2026. Uniform and class-balanced objectives are adjacent pairs within each representation/rate/seed. Every attempt performs one cycle of 256 training rows with 16 wholly disjoint held-out groups, no transformations and the existing 0.05 maximum delta/gradient bound. The held-out weights and strict exact/class/severity/action/publication guards remain unchanged.

`prepare_training_objective_artifact` adds or removes only the validated objective metadata on a deep copy and recomputes the internal checksum. Final-block attempts first use the existing opt-in preparation helper. Preparation must preserve original parameter values, shapes, configuration, model ID and version; trainable flags change only for the predeclared final-block representation. The uniform control has no objective metadata key and preserves original example weights; it does not assert that every row has weight one. Class balancing splits rows using the explicit target's `classification_is_sensitive` result. If total original weight is W and the original weight sum in a row's class is Wc, its effective weight is W × (original weight / Wc) × 0.5. Both classes must be present with finite positive weights. Each class therefore receives half of W while within-class relative weights are preserved. This changes the supervised training objective, not labels, inference policy, held-out metrics or publication thresholds. Response metadata must preserve the nine numeric audit fields: training clean/sensitive counts, raw clean/sensitive/total weights, effective clean/sensitive weights and clean/sensitive objective masses. Uniform controls emit none of these class-balanced audit fields. Actual class/role coverage and paired train/held-out text/group commitments must be preserved, and paired inventories must be identical before any selection claim.

The existing 2,300-row curriculum is reused unchanged: 2,172 retained public-negative/bootstrap rows and 128 assistant-authored contrastive examples across 16 whole families. Validation-overlapping groups were removed by the frozen preparer. Public negatives and contextual targets remain provisional, without independent human contextual review. External PII annotation presence supplies no severity, visibility or action truth; fixture rows or families never enter training.

The paired inventories additionally bind ordered original texts, normalized text keys, groups, full sensitivity/visibility/category targets and original row weights with SHA-256 for both train and held-out partitions. The class strata use contextual classification, not external annotation presence. Seeds contain only 6, 8 or 9 sensitivity-positive training rows; assigning those rows half the objective mass amplifies sparse provisional supervision and does not create new evidence. Existing held-out metrics and severity/action guards are row-based, despite earlier descriptions calling them weighted; their computations, inputs and acceptance thresholds remain unchanged.

Before the first fit, initialize snapshots all seven exact live model payloads and five original immutable image IDs. Freeze current computation sources, both study controllers, initial and phase-specific reporters, the preparer, overlay, protocol, preparation manifest/curriculum and prior live-validation parity proofs. Root-built feature runtime/streamer/updater images are separately pinned to immutable IDs. Automatic startup training must be disabled. The original catalog and images are restored and compared exactly after every mutating stage, including rejected/failed attempts. Partial attempt directories, durable request IDs, unknown outcomes or active failures forbid blind retry.

The new feature images must first reproduce all 968 previously frozen live-balanced validation classifications, presence decisions and actions with zero per-case differences against the matched artifact and model identity. Confidence and latency are not compared as classification parity. The pinned prior semantic report SHA-256 is `6fda10af4810d1045dc977473391e13360ed00d70abfa4c8811db2009652d1a7`; pipeline report SHA-256 is `f931cc651116ffea9d89d8a73bc52efe9af2f42504a25b041266710a36bcf1e8`. Their semantic counts are TP246/TN155/FP338/FN229 and pipeline counts TP427/TN143/FP350/FN48. The fresh feature-image baseline must be measured and reconciled rather than assumed compatible. A parity failure stops fitting.

Fresh live-balanced development predictions and all 48 contextual fixture responses are measured and archived before the grid. These reference measurements are independent of candidate selection; no candidate development or contextual fixture inference occurs before selection is frozen. Each accepted candidate is evaluated on all 968 validation rows, with 475 positives and 493 negatives, using semantic and full-pipeline reports with zero errors and matched IDs, truth, groups, checksums and fingerprints. Rejected updates receive no model-quality score.

All 24 attempts must terminate and restoration must pass before freezing selection. Eligibility requires pipeline TP at least 428/475 and TN strictly above the fresh same-base validation baseline. Rank eligible candidates by TN, TP, lower learning rate, lower seed, uniform objective on a tie, then heads on a remaining tie. Only validation selects the winner. There is no selection on development or fixture outcomes and no alternative candidate after a failed retention decision. With no eligible candidate, no candidate endpoint inference is performed.

Assess the frozen winner once on the 502-row reused development partition, containing 264 positives and 238 negatives. Retention requires pipeline TP at least 238/264 and TN strictly above the fresh live-balanced reference. It additionally requires zero newly introduced minimum-action failures on private disclosures and zero new WARN/BLOCK outcomes on previously allowed clean fixture controls, compared case by case. Existing baseline failures remain visible; aggregate improvements cannot cancel new harms. The fixture has 41 quantitative provisional cases and seven ambiguous cases excluded from the retention gate. Annotation presence is not substituted for fixture contextual targets.

A retained artifact is a research selection only; restore the entire original catalog and images, with no default promotion. Report every setting and rejection, semantic and pipeline supports/recall/specificity/precision/F1/balanced accuracy, source strata with null rates for absent classes, paired changes, exact model identity/configuration/trainability, actual sampling coverage, true training-objective audits and service-only latency. Legacy classification-distance diagnostic loss and optimized supervised objective loss have different scales and must be labelled separately. Profile capacity, confidence calibration, broad seed stability, production latency and statistical superiority are not established by this grid.

Use the staged controller `evaluation/run-class-balanced-fuzzer-study.py` with a fresh direct-child output such as `evaluation/results/class_balanced_fuzzer_20261006_v1`. `plan` is read-only; `initialize` snapshots/freezes without fitting; `baseline` validates parity and archives the fresh references; `candidates --limit 1` executes the next reserved independent attempt; `freeze` requires all 24 terminal attempts; `finalize` measures only the frozen winner. Root owns image builds, all service/model execution, independent review and final reporting. This protocol becomes immutable before the first phase 02 fit.
