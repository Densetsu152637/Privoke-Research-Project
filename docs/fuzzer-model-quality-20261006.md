# Contextual fuzzer model quality

This is the reporting method for the controlled study in `evaluation/results/contextual_fuzzer_20261006_v2`. The measured report is saved separately as `docs/fuzzer-model-study-v2-quality-20261006.md`, with JSON evidence alongside the results. A report marked partial does not certify a completed assessment. Failed study v1 is separate evidence and must not be pooled with v2.

Use `evaluation/report-contextual-fuzzer-study.py` to read preserved evidence without contacting Docker or a model service. It prints to standard output and never trains, updates, scores new examples, or opens the protected final partition. A complete report requires three original baselines, all 54 terminated attempts, frozen selection, a recorded endpoint decision and verified restoration. An incomplete or failed study requires `--partial`, which marks every missing measurement and unscored accepted response explicitly.

```powershell
python -B evaluation/report-contextual-fuzzer-study.py --self-test
python -B evaluation/report-contextual-fuzzer-study.py --study evaluation/results/contextual_fuzzer_20261006_v2 --partial --format json
python -B evaluation/report-contextual-fuzzer-study.py --study evaluation/results/contextual_fuzzer_20261006_v2 --format markdown
```

The reporter checks preserved source copies, curriculum and endpoint hashes, artifact checksums, parameter fingerprints, exact prediction IDs, annotation-presence truth, source groups, runtime errors and raw/aggregate count agreement. Inference fingerprints include tensor shapes; training metadata fingerprints use the distinct value-only format with null shape placeholders. A skipped pipeline layer may record an explanation after regex BLOCK; a failed layer invalidates scored evidence. The streamed classifier legitimately returns no detection items for S0/PU/no categories. Such responses have no per-case model identity; provenance combines explicit model requests, frozen sources/catalog/images and matching returned identity items elsewhere in each complete live/winner collection. Every returned item must match, and a collection with no identity evidence is rejected.

Quality means measured behavior. The report includes original efficient/balanced/quality and every accepted candidate, with semantic and pipeline TP/TN/FP/FN, recall, specificity, precision, F1, balanced accuracy and source-specific supports. An absent source class produces a null rate, not zero. Poor performance on a source is evidence of model/source mismatch; it does not by itself establish poor dataset quality. Paired transitions identify semantic misses recovered by the pipeline, added clean flags with returned regex/NER signals, and changes against the same-profile original. Regex and NER co-occurrences may overlap and do not establish causation.

The report also preserves model IDs, versions, immutable checksums, actual parameter/trainable counts, configuration dimensions, exact frozen/trainable tensor names, rate/seed/strategy and actual sampled role/class/family inventories. The declared seeds are 42, 1337 and 2026; this grid does not establish broad seed stability. Counts of S1/S2/S3 rows describe provisional sensitivity labels rather than independent contextual truth. Held-out exact, sensitive-recall, clean-specificity and combined severity/action guards use row counts, not example weights, and are shown before and after. Legacy `average_loss` is a weighted classification-distance diagnostic; last-block `supervised_objective_loss` is the weighted sensitivity/visibility cross entropy plus summed category BCE used for training. These losses have different meanings and scales.

Execution amendments remain separate, immutable evidence. A recovered measurement must bind the original request, base, accepted response and candidate without repeating training or changing training computation or selection. Missing original wall time stays null; recovery scoring time is separately identified. An administrative verifier failure is not converted into a model rejection or an accuracy result.

Selection uses all predeclared validation attempts, with pipeline recall at least 90% and strict specificity improvement against the same-profile original. Only the frozen winner may receive the development and contextual fixture assessment. Development requires recall at least 90% and strict specificity improvement against measured live balanced. The provisional fixture gate forbids every newly introduced minimum-action failure on private disclosures and every new WARN/BLOCK on a previously allowed clean control; aggregate improvements cannot cancel new harms. Annotation presence is not substituted for fixture severity, visibility or action labels. Seven ambiguous cases are excluded from the quantitative fixture gate.

Service `elapsed_ms` summaries include the first request and exclude browser/bridge overhead. They do not establish representative production latency or confidence calibration. Encoders originate in repository-owned seeded random initialization, and original heads use authored bootstrap supervision. The curriculum's public negatives and newly authored contextual labels are provisional, without independent human contextual review. Validation and development are reused exploratory evidence; no final generalization, statistical superiority, complete span recovery or deployment-safety claim follows from this study. The protected final examples and labels remain uninspected and unscored.
