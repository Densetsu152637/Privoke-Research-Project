## Recorded validation checkpoint

The detector worker passed 67 client-runtime unit tests at its isolated detector revision, source/test compilation, 2,000 deterministic Unicode normalization compatibility checks, and Git diff checks. The browser worker reported 84 passing isolated browser tests. These counts do not include later integrated training/receipt changes and do not substitute for release CI. No additional source test run is claimed by this documentation update.
