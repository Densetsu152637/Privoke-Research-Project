Development artifact changes are backed up and restored byte-for-byte. The primary checkout remains unchanged. Local detailed logs are ignored under `dumps/implementation/`.

## Remaining release validation

- Required PR CI must pass for the final revision and an SA approval must be recorded before an authorized non-author merges it.
- Live native-host/website checks for supported browser families/endpoints, GPU execution, external LM Studio/OpenAI inference, actual cloud provisioning and public benchmark reruns remain unverified. Unit fixtures and local cloud topology checks do not establish those results.
