## Stage 3: Adversarial privacy-evasion evaluation

- **Objective:** meet G6.
- **Depends on:** Stage 1.
- **Owned paths:** all of these are new files.
  - `evaluation/adversarial_evasion*.py`
  - `evaluation/tests/test_adversarial_evasion*.py`
  - `paper/research/adversarial-evasion-2026111X.md` and its JSON
  - `docs/experiments/adversarial-evasion-*`
- **Method:**
  - **Seed set:** the full labelled sensitive set of a declared evaluation split. The split must be disjoint from every set used to design the default-off robustness flags; the record declares which sets those were.
  - **Baseline:** report detection on the untransformed prompts.
  - **Evasion:** a prompt evades when it was detected before the transform and is missed after it. Report both conditional and unconditional ASR.
  - **Transforms:**
    - Unicode homoglyphs and zero-width characters
    - inserted spaces
    - spelling perturbations
    - paraphrase
    - indirect reference
    - encoded identifiers: base64, hex and spelled-out digits
    - long-context placement
    - multilingual variants
  - **Pipeline:** run the full product pipeline, recording which layers executed. Report the shipped defaults and the default-off robustness flags as paired arms.
  - **Labelling:** results are product-pipeline evidence, never LLM-only. Do not use the legacy `--allow-product-pipeline` study commands.
- **Acceptance checks:** G6. The seed is deterministic, and the set's hash is frozen before scoring.
- **Status:** pending.
- **Outcome:** none yet.
- **Handoff notes:** paraphrase, indirect-reference and multilingual variants must come from declared templates or from a generator whose revision is recorded. They must never be hand-tuned against PriVoke's outputs.

## Decision, 16 November 2026: nginx and the Rust rewrite

Its removal is therefore sequenced in [the Rust rewrite plan](rust-server-rewrite.md), after the services enforce mutual TLS themselves. The paper describes the measured current system.
