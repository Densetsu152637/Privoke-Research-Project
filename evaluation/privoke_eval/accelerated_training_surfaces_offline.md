# Accelerated offline adapter

`privoke_eval.accelerated_training_surfaces_offline.fit_cell(cell, inputs, output)` fits a single prospectively frozen TRAIN-only cell. `inputs` contains `train`, `assets`, `source_revision`, and optionally `base_artifact`; references contain exactly `path` and `sha256`. Tiny and random control require a prepared 256-position base artifact. Generated sparse, scratch and MiniLM initializers reject unrelated base artifacts. Binary rows require explicit `present: bool`; contextual rows require `classification`. No target conversion is inferred.

Tiny and frozen-head cells take 96 optimizer steps of 32 presentations. Scratch preserves its native maximum batch of 16: 96 steps and 1536 presentations, explicitly unequal to the other surfaces. All neural orders cycle seeded shuffled TRAIN permutations. Scratch uses the maintained canonical initialization seed 12102026; replicate seeds 42/43/44 change sampling order. Head/full modes share initial parameter fingerprints. Scratch contexts remain 64/96/128 and overlength TRAIN/evaluation rows fail explicitly.

Sparse fitting freezes `solver='lbfgs', max_iter=1000, tol=1e-4, C=1.0, class_weight='balanced'`, following `fit-presence-profiles.py:137` and train-only `in_house_study_fit.py:61,742`. Threshold is 0.5. Its baseline is a zero head on TRAIN-fitted TF-IDF vocabulary/IDF, created before logistic fitting; it is not a shipped baseline. Native iterations and convergence warnings are recorded. Nonconvergence fails without extending the budget; sparse dose is never described as 96 minibatch updates.

MiniLM uses the official hash-verified 256-token frozen encoder. The random control projects frozen prepared Tiny features with a fixed Gaussian seed 12102026 to 384 dimensions and applies L2 normalization. Both arms use identical per-replicate 384-dimensional head initialization, Adam implementation, order, and dose. This is a representation-package comparison; it does not isolate pretraining or model size. Control snapshots use the explicit offline-only `accelerated-random-control-v1` schema and retain projection bytes and identity.

Scratch zero-step baselines use `accelerated-initialization-v1`, with config, parameters, initialization fingerprint and actual zero steps. Native final artifacts retain the release validator and export parity checks. No shared release schema is weakened.

`evaluate_cell_snapshot(path, rows, layers, assets=None)` requires exactly `['DETECTION_LAYER_SEMANTIC']` before accessing files. It returns one record per input row: successful learned forward passes carry executions, identity, snapshot hash and fingerprint; failed passes carry errors and no fabricated successful execution. This is an offline trace, not protobuf transport evidence. The same evaluator reconstructs both initial/final snapshots. MiniLM evaluation requires explicit pinned asset references.

Outputs are exclusive. Completed receipts resume only after input/source commitments and all output references verify. Interrupted directories remain inspectable and require fresh output directories. Baselines are persisted before parameter fitting; only fixed-final artifacts appear in checkpoints. Step order, losses, optimizer state, source hashes, actual dose and exported inference parity are retained. No assessment-driven threshold/checkpoint selection occurs.

Preliminary synthetic mechanics run on host Python 3.13.2, NumPy 2.4.1, Torch 2.12.0+cpu and scikit-learn 1.9.0. These are not study-fit pins. Pinned Linux integration must validate the training closure and MiniLM closure before any study fit; MiniLM requires NumPy 2.2.6, ONNX Runtime 1.23.2 and tokenizers 0.22.1. No global package installs or services are needed for source checks.

Completed resume validates schema, status, exact cell/settings/source identity, exact required surface evidence references, output filenames constrained to the cell directory, checkpoint reference and bytes hashes. `evidence` contains only references; scalar observations are separate in `evidence_metrics`. The outer study controller must freeze the receipt hash independently to detect coordinated replacement of receipt and content.

Offline random-control snapshots declare deterministic versions `accelerated-control-seed{seed}-step0` and `accelerated-control-seed{seed}-step96` and actual `training_steps` 0/96. Evaluator traces validate and propagate both values. The initialization-zero-step identity is reserved for the genuine zero-step scratch initialization schema. Random control has direct-forward numerical parity checks; native-serving parity is unsupported for this offline-only projected representation.
